# Web Security Auditor — GitHub Actions runner

Public, constrained Python runner for website security posture. See the private skill at `ngocnhanvo/web-security-skill` (only authorized users can access).

The default scan is public and non-invasive. Active probes require a fresh owner-hosted, exact-host permission file and explicit allowlisted paths. No credential attacks, brute force, denial-of-service, state-changing requests, data extraction, or out-of-scope traversal.

**Do not assume deployment or scans are working until workflow runs and reports have been verified.**
