# ESC WordPress admin exposure false-negative correction — 2026-11-24

## User evidence and initial root cause
The operator provided a screenshot of `admin.esc.vn/wp-login.php?redirect_to=...&reauth=1` showing the standard Vietnamese WordPress login interface, username/email input, password input and login button. The previous automated admin review recorded two HTTP 302 responses and classified the destination as NOT TESTED, due to a one-redirect limit and a blanket rejection of URL queries. Its offline Chromium classifier recognized only literal admin text labels; translated WordPress forms lacked this label. Therefore earlier "no observed admin" conclusions were incomplete and constituted a false negative, not a security pass.
